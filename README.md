# SYSWATCH - System Resource Monitoring Tool


## Features

- Displays CPU Usage, Network Usage, Memory Usage, and Processes in real-time.
- Shows updates.
- Lightweight command line utility.

## Steps to Run

1. Make sure `Go` compiler is installed.
> Get the latest one @ https://go.dev/doc/install

> Check with:
> ```
> go version
> ```

2. Clone this repo and compile.
```sh
git clone https://github.com/dagger021/syswatch.git

cd syswatch

go run cmd/syswatch
```

OR, directly install and execute with:
```sh
go install https://github.com/dagger021/syswatch/cmd/syswatch@latest

```
